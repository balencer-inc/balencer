# 議事録の顧客タグを埋める

Notion議事録DBは**顧客タグが空の回がある**。空だと月次レポート・顧客ページのロールアップ・検索から漏れる。
このスキルはタイトルから顧客を推定して埋める。**推測が入る作業なので、確度で3段に分けて扱う**。

- 議事録DB: `collection://21753269-fc5e-80ee-b22a-000bacba9a0b`
- 顧客管理DB: `collection://2ef07b20-436f-435d-a869-bc57eeb7c57c`
- Notion は claude.ai の Notion コネクタ（`mcp__claude_ai_Notion__*`）。`notion-mcp`（APIトークン）は401で使えない

タグは **顧客（select）と 関連顧客（relation）の二重管理**。両方入れる。

---

## 1. 現状を測る

```sql
SELECT COUNT(*) AS 全件,
       SUM(CASE WHEN "顧客" IS NULL AND "関連顧客" IS NULL THEN 1 ELSE 0 END) AS 両方空,
       SUM(CASE WHEN "顧客" IS NULL THEN 1 ELSE 0 END) AS select空,
       SUM(CASE WHEN "関連顧客" IS NULL THEN 1 ELSE 0 END) AS relation空
FROM "collection://21753269-fc5e-80ee-b22a-000bacba9a0b"
```

## 3. 確度で3段に分ける

| 段 | 判定 | 扱い |
|---|---|---|
| **確定** | タイトルに社名・ブランド名が入っている／select値からの機械変換 | そのまま書き込む |
| **要確認** | 人名のみ。上の人名表にあるものだけ確定に昇格 | 表にない人名は阿部さんに聞く |
| **不明** | タイトルが空／「ミーティング」「新規打ち合わせ」等の一般語／顧客selectに選択肢がない会社 | 書かない。一覧にして渡す |

**顧客selectに選択肢がない会社は触らない**（2026-08-27 阿部さん判断）。オイシーズ・HASSIN・サカヒラ・原鉄筋工業・ONE MORE・レインボーボイス・北山商事・ASAHI・ソーケンが該当。埋めるにはselectオプションの追加が必要。

## 4. 書き込み

```
mcp__claude_ai_Notion__notion-update-page
  page_id: <議事録ページID>
  command: update_properties
  properties: {"顧客": "睦備", "関連顧客": ["https://app.notion.com/25e53269fc5e80d8809cde70fe7cb748"]}
```

- relation は**ページURLの配列**で渡す
- 空の項目を埋めるだけ。**既に値が入っているものは上書きしない**（WHERE で IS NULL を必ず付ける）
- select が既にある行は `関連顧客` のみ渡す
- **必ず1件テストしてから一括する**。書き込み後にSQLで読み直して入ったことを確認する
- 一括はバッチ10件並列が目安。1件ずつしか更新できるAPIがないため件数分の呼び出しが必要

## 運用

- **`monthly-report` の直前に走らせる**のが本来の使い方。タグを埋めてからレポートを作れば取りこぼしが減る
- 毎月やる必要はない。空タグが溜まってきたら（1章のカウントで確認）実行する
- 根本解決は**議事録を作る時にタグを付けること**。Notionのテンプレート（`新規item`）に顧客プロパティを必須にする案は未検討
