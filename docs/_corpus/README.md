# _corpus — 阿部さんの一次資料

AIが阿部さんとして書くときに参照する場所。会社文書（`docs/company/`）とは役割が違う。
会社文書は「会社は何者か」の正本、ここは「**阿部さんはどう言うか・何を大事に決めるか**」の正本。

| フォルダ | 種別 | 中身 |
|---|---|---|
| [abe-voice/](abe-voice/) | **文体源** | 音声入力の生テキスト。どう話すか |
| [abe-shiso/](abe-shiso/) | **思想源** | 判断基準・価値観・自覚している矛盾・未解決の問い。何を大事に決めるか |

---

## abe-voice（文体源）のルール

| | |
|---|---|
| ✅ 入れる | 音声入力の**生テキスト**（フィラー・言い直し・誤変換つき）／メールや議事録での阿部さん自身の発言／セミナー・面談の文字起こし |
| ❌ 入れない | **AIが整形した文章**／編集者や誰かの手が入った原稿／会社の公式文書 |

**整形後の文章を文体源にしてはいけない。** AIが整えた文をAIが学ぶと自家中毒になり、阿部さんの文体でなく「AIが整えた文体」が再生産される。松浦勝人さんが文体源をブログに絞り、編集者の手が入る雑誌連載を外したのと同じ判断（→ [marketing-matsuura-method.md](../_knowledge/marketing-matsuura-method.md)）。

**誤変換や言い間違いも直さない。** 「死体となるのを」（＝「主体となるものを」の誤変換）のような崩れは残す。崩れ方まで含めて文体であり、直すと整形後に近づく。事実として引用するときだけ、書き手が文脈から正しく読む。

## abe-shiso（思想源）のルール

- 文体源には**しない**（整形済みの文章なので、文体を真似ると自家中毒になる）
- 正本は個人Obsidian Vault（非共有）。ここにあるのは**数字と家族の機微を落とした投影**
- **私的な数字をここに書かない。** このリポジトリはメンバーがClaude Codeで開けば読める。資産・家族・私生活の具体はVaultに置く（二脳設計）
- Vaultの正本を直したら、こちらを焼き直す。こちらだけ直して終わりにしない

## 読み方（全部読ませない）

コーパスは育つほど大きくなる。**全文を常時読ませない。** 索引を見て、必要な回だけ開く。
索引: [abe-voice/INDEX.md](abe-voice/INDEX.md)

足りなければ阿部さんに聞く。無いものを埋めて書かない。
