# お題の在庫（月曜に1本ずつ出す）

**お題を出すのはAI側の仕事。** 阿部さんに「何を喋りますか」と聞かない（それを考えるのが一番面倒な工程なので、そこで止まる）。

出し方のルール:
- 月曜、この在庫から**1本**選んで出す。5〜10分で喋れる粒度に割る
- 出すときは「質問」＋「ねらい」＋「こう話すと刺さる」の3点を添える（Notionのネタ帳と同じ形）
- **その週の実務から拾ったお題を優先する**（顧客フォルダの動き・議事録・失敗）。在庫は実務が静かな週の保険
- 喋ってもらったら在庫から消し、[INDEX.md](INDEX.md) に1行足す
- 阿部さんが「その問いは違う」と返したら、それも回収する（→ [recruit-joushiki-hitei](2026-06-13_recruit-joushiki-hitei.md) が実例）。外れた問いの記録が、お題の精度を上げる
