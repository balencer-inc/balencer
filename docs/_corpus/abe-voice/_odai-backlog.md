## Notion側の仕組み（2026-08-24 構築）

`状況` という数式列が自動で3つに分けている。**手でタグを付け替える作業はない。**

| 表示 | 条件 |
|---|---|
| 🎙 未収録 | 生声チェックなし＝これから喋るお題 |
| ✅ 収録済み | `🎙生声` にチェックあり |
| ⚙️ 運用メモ | タイトルが `【` で始まる（お題ではない運用メモ・成果物） |

阿部さんが吹き込んで `🎙生声` にチェックを入れれば、勝手に未収録から消える。お題でないページを在庫から外したいときは、タイトルの頭に `【` を付ける。

## AI側の仕事

1. **月曜、実務から拾ったお題があればNotionに1本足す**（顧客フォルダの動き・議事録・失敗・試して外したこと）。在庫から選ばせるのは実務が静かな週の保険
2. 吹き込まれたら **Notion → git へ回収**して [INDEX.md](INDEX.md) に1行足す（→ 手順は [marketing スキル](../../../.claude/skills/marketing/SKILL.md)の「音声インテーク」）
3. 阿部さんが「その問いは違う」と返したら、それも回収する（→ [recruit-joushiki-hitei](2026-06-13_recruit-joushiki-hitei.md) が実例）。**外れた問いの記録がお題の精度を上げる**

## お題を作るときの観点

- **本人の中の矛盾を突く問い**が一番濃い（例: 人には切るなと言うのに経営者には自我を捨てろと言う、その非対称はなぜ？）
- **まだ決めていないこと**を聞くと、喋ることが答えを出す作業そのものになる（→ [../abe-shiso/人生設計_思想の芯.md](../abe-shiso/人生設計_思想の芯.md) §9の未決論点）
- **失敗・読み違え**は信頼を一番生む
- きれいに解決していない話でいい。むしろ解決していない方がいい
