# samples — 作り方の見本を置く場所

社内で「この作りを真似したい」と判断した成果物の実物を置く。**構成とレイアウトを見るための資料**であって、中身を流用するためのものではない。

## 置いてあるもの

### miraclenurse_strategy_202608.pdf

- 加藤梨紗さん作「株式会社Miracle nurse 御中 マーケティング戦略書」（2026-08-25／10ページ／A4横）
- 合同会社ホコロビ名義。design-md の `meiji` を適用
- **この資料を型にしたのが `client-deck` スキル**。作り方の6手順はそちらが正本
- 見るポイント: ページ構成の順番（診断型）／等幅・等高カードのグリッド／数字を特大にして単位だけ小さく／悪い数字はアクセント色・良い数字は黒

**取り扱い（重要）**

- **社外に出さない。** 他社（ホコロビ・Miracle nurse様）の契約金額、アイドマHDとの減額交渉の状況が入っている
- バレンサー名義の資料に流用する時も、**金額・交渉状況の類は持ち込まない**。借りるのはページの順番とカードの組み方だけ
