# 税理士への月次提出（領収書＋カード明細）

領収書の紙とカード決済明細を、毎月ノートに貼って蛍光ペンで塗って郵送していた工程をデータに置き換える取り組み。
ロードマップ [#19](../../_knowledge/ai-automation-roadmap.md)。**2026-09-03 時点は現状把握フェーズ。設計・実装はまだ。**
狙いは領収書 × カード明細の突合の一点（通帳・銀行明細は経理判断でスコープ外）。
出口の形式は税理士事務所の回答待ち＝ここが最大の制約。

## 毎月の使い方（暫定）

1. 領収書を撮って、カード明細PDFをDLして、[_inbox/](_inbox/) に放り込む
2. Claude に「税理士提出の突合お願い」と言う → リネーム・月次フォルダ振り分け・突合表生成
3. 突合表を見て、「なし」の行に対応する領収書を探すか、理由を書く
4. 原本は封筒に入れて送る（ノートに貼らない）

## ファイル名の規則

- 領収書 … `YYYYMMDD_<支払先>_<金額>円_<カード|現金>.jpg`（日付は領収書の日付＝利用日）
- カード明細 … `YYYYMMDD支払_<カード名>_締YYYYMMDD.pdf`
- 月次フォルダ `YYYY-MM` … **税理士に渡す束の単位**（利用月ではない。カードの締めで境界が決まる）
