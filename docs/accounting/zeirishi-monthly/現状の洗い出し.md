## 1. いま何をやっているか（2026-09-03 阿部さんヒアリング）

### 紙の運用（現行）

1. 領収書を溜める
2. **ノートに日付順で貼り、ファイリングする**
3. カード決済明細を印刷し、**蛍光ペンで3色に塗り分ける**
4. 通帳のコピーを取り、**それが何費かを手書きで書き込む**
5. 一式まとめて**郵送**する

### 蛍光ペンの3色（この意味づけが自動化の中核）

| 色の区分 | 意味 |
|---|---|
| あり | その明細行に対応する領収書が揃っている |
| なし | 領収書がない |
| その他 | 上記以外（固定費・サブスクなど） |

### ヒアリング回答（§7の5問）

| # | 質問 | 回答 |
|---|---|---|
| ① | 税理士側が受け入れられる形式 | **未確定＝最大の制約**。渡した相手はそれを見ながらPCに入力している（＝会計ソフトへの手入力）。要確認 → [税理士への確認事項.md](税理士への確認事項.md) |
| ② | 対象範囲 | 領収書（紙）／カード決済明細／買掛側の請求書／通帳・銀行明細 の4種 |
| ③ | 枚数の実感 | 領収書 **月30〜100枚** |
| ④ | カード | **1枚（セゾンプラチナビジネス AMEX）。Web明細のPDFをDL可** |
| ⑤ | 電子帳簿保存法 | **紙で全部保存している**。電帳法対応は意識していない |

### 自動化のスコープ（経理担当の判断で確定）

| 対象 | 扱い |
|---|---|
| 領収書（紙） | **やる** |
| カード決済明細 | **やる** |
| 買掛側の請求書 | 元がPDF（メール受領）。すでにデータがある＝優先度低 |
| 通帳のコピー＋何費かの手書き | **やらない**（経理より「自動化しなくていい」） |
| 銀行明細 | **やらない**（経理より「特に何かして欲しいわけではない」） |

→ **狙うのは「領収書 × カード明細の突合」の一点**。ここが紙の手作業のほぼ全部。

## 2. サンプル実測でわかったこと（2026-09-03）

材料: カード明細PDF 1本（2026-08-04支払・締2026-07-14）＋ 領収書写真4枚

### わかったこと

1. **セゾンのWeb明細PDFは機械可読**。`pdftotext -layout` で明細62行を全部取れる
   → 印刷して蛍光ペンで塗る工程は、そのまま表の生成に置き換えられる
2. **検算が通る**。抽出した62件の合計 833,756円 が明細記載のご請求金額と**完全一致**
   → 取りこぼしゼロを機械的に証明できる（経理の「読むのは自動、書くのは人」に合う）
3. **領収書の写真は読める**。4枚すべてから日付・支払先・金額・消費税・登録番号を抽出できた
4. **突合は金額＋店名で当たる**。4枚のうち2枚が明細行に一致した
   - `CarneSio West 2026-06-21 9,900円` → 明細 `CarneSio WEST` に一致
   - `秋吉 西中島店 2026-07-03 7,980円` → 明細 `秋吉 西中島店` に一致
5. **残り2枚は締め期間の外だった**（明細に存在しない）
   - `川福 箕面小野原店 2026-07-14 4,670円`
   - `じげん 2026-08-13 7,381円`

### 詰まりどころ（設計で必ず効く3点）

**(A) カードの締め期間と月がズレる**
この明細は **6/15〜7/14利用分を8/4に支払う**。「8月分」と言ったときに、支払月・締め月・利用月の3つが指すものが違う。
利用日7/14の領収書は、この明細に載らず次回に回る。**領収書の束をどの月に入れるかは、この境界で決まる**。
→ サンプルでは 川福・じげん を `2026-09/` に回した。スクリプトはこの2枚を「締め期間外」として弾くことを確認済み。

**(B) 領収書のない行が34件ある（62件中）**
現状の分類結果は あり2 / なし34 / その他26。「なし」34件のうち相当数は、領収書を撮り漏らしているのではなく
**そもそも紙が出ない支出**（Web領収書をDLするタイプ）と思われる。ここを詰めないと「なし」が使えない情報になる。

**(C) 家族カードの利用が10件混ざっている**
明細に家族欄フラグ付きの行が10件（書店・アマゾン・ディプティック等）。
経費/私費の線引きは人の判断。**AIは分類せず、家族カード行として分けて出すだけ**にする。

## 3. 目指す姿（叩き台・未確定）

紙の5工程を、こう置き換えられる見込み。

| 現行 | 置き換え後 |
|---|---|
| 領収書をノートに貼る | **貼らない**。撮って所定フォルダに入れる。原本は封筒にざっと入れて送る |
| 日付順にファイリング | ファイル名の日付で自動的に並ぶ（`YYYYMMDD_支払先_金額円_カード/現金`） |
| 明細を印刷して蛍光ペンで3色 | **突合表を自動生成**（3色を色分けしたHTML/CSV/PDF） |
| 一式を郵送 | 色分け明細＋領収書画像はデータで渡す。原本のみ封筒で送る |

**郵送はゼロにはならない**（原本の保存義務がある。電帳法のスキャン保存に乗せるかは税理士の指示待ち）。
ただし**ノート貼りとファイリングは丸ごと消える**のが今回の最大の効果。
