# HMC2026 登壇準備・営業ツール制作 進行計画

- **更新日**: 2026-09-07（2026-08-24 MTG後の追記をファイル化）
- **正本**: Notion「0824戦略ミーティング（2026-08-24）」末尾の追加対応セクション
- **位置づけ**: フェーズ1（月額契約2件の獲得）の主力施策。登壇そのものではなく**認知→会話→リード獲得→商談化までを一連で設計する営業施策**として進める

## 全体像

11月のHMC2026（業界カンファレンス・出展費65万円）への登壇を軸に、以下の2系統を並行して制作する。

1. **HMC2026 登壇用一式**（イベント当日の導線）
2. **通常営業用A4一枚資料**（紹介・日常営業の道具・費用3万円）

当日の配布物と通常営業用チラシは**目的が違うので分けて設計する**が、プロフィール・実績・ロゴ・写真などの素材回収は共通化する。

## 重要スケジュール

| 期限・日程 | 対応内容 | 完了条件 |
|---|---|---|
| **9月18日（金）** | 企業・登壇者・セッション情報、登壇者写真、ロゴデータを提出 | 主催者の情報管理シートへの記入・提出が完了 |
| 9月中 | 登壇の基本設計を確定 | 対象者・テーマ・持ち帰ってほしい結論・入口商品・CTAが決定 |
| 10月2日（金）目安 | 登壇資料の社内確認版を作成 | 杉山さん・阿部で内容確認できる状態 |
| **10月9日（金）** | 登壇資料初稿を主催者へ提出 | 30分登壇の全体構成と主要スライドが完成 |
| 10月14日（水）15:00 | 主催者とのオンライン事前MTG | 当日の進行・修正点・最終リハーサル日程を確認 |
| イベント前 | LP・診断・配布物・追客準備を完成 | 登壇から相談までの営業導線が通しで確認できる |

> ⚠️ **10月14日に内容を考え始めるのでは遅い**。実質的な内容確定期限は10月上旬。10月14日は10月9日提出の初稿をもとに主催者と進行・修正点をすり合わせる場。

## 登壇内容で先に決めること

- [ ] 誰に最も届けたいか（※大手チェーン・鉄道系は担当者もブランドもあるためターゲット外。**FC運営会社・中小オペレーターが本命**）
- [ ] 参加者に持ち帰ってほしい結論
- [ ] 登壇タイトルと30分のストーリー
- [ ] 紹介する事例と掲載可能な数値
- [ ] 「外部RMチーム」をどのように伝えるか
- [ ] イベント専用の入口商品
- [ ] RM体制診断・個別相談の内容
- [ ] 登壇後のCTAと専用LP
- [ ] 当日アンケートで取得する情報
- [ ] 当日会話した相手の記録・分類方法
- [ ] イベント後24時間以内の追客方法

> 打ち出しの軸（8/24 MTGの合意）: **「レベニューへの独自の切り込み方」**。レベニューを名乗る会社は多いが、Clavisのように現場に入り込んでやっているところは少ない — ここを一つ残す。

## 素材回収後の進め方

1. 杉山さんから共通素材を受領
2. バレンサー側で不足情報と掲載可否を確認
3. 通常営業用A4一枚資料の構成を作成
4. 登壇テーマに合わせてイベント配布物へ再編集
5. 専用LP・診断・登壇資料と表現・CTAを統一
6. 主催者提出前に全体導線を確認
