# 睦備建設様 月次レポート

専務へ毎月お出しする**A4横1枚の月次報告**。定例に出ていない役員が「今月どんな会議で何を話したか」を1枚で掴める状態を作るための資料。

- **作り方の型**: `.claude/skills/monthly-report/SKILL.md`（「月次レポート作って」で発火）
- **デザイン**: `meiji`（明治／awesome-design-md-jp）を適用
- **サイクル**: 月末に作成 → 月初に専務へお渡し
- **材料**: Notion議事録DB（`顧客=睦備` または `関連顧客=睦備建設`）のページ本文にあるAI議事録サマリー

## 構成（4ブロック固定）
1. 今月の会議（日付・会議名・主なテーマの表）
2. 今月のポイント（役員が知るべき変化を3つ）
3. テーマ別の進捗（最大6枚のカード。5領域＋お客様の声）
4. 来月の重点 ／ ご判断をお願いしたいこと

## 運用ルール（重要）
- **gini定例は材料から除外**（2026-08 判断）。ベンダー間会議には見積の内訳交渉やバレンサー側の工数管理が含まれ、そのままは出せない。「開発ベンダーとの実務定例を週次で実施」の一行注記のみ入れる
- クライアント同席の会議で出た金額は、**確定額でない旨を明示して**載せる
- 議事録DBは顧客タグが空の回があり（DB全体で約2割）、その回は拾えない。取りこぼしの可能性は毎回報告する
- A4横1枚は `overflow:hidden` で切れても1ページPDFができてしまうため、**スクリーンショットでフッターまで見えているか必ず確認する**
