# 動作確認チェックリスト（本番前に必ず）

本番と同じスマホ・同じスピーカー接続で確認してください。
できれば**当日と同じ会場**で一度通してリハーサルを。

## A. 事前準備（電波のある場所で）
- [ ] 本物のmp3を `audio/` に全部配置した
- [ ] `index.html` の `DEV_SYNTH_FALLBACK` を `false` にした
- [ ] スマホのブラウザでURLを開き、ホーム画面に追加した
- [ ] **ホーム画面のアイコンから起動**して、フルスクリーンで開くことを確認
- [ ] 全BGMボタン・全効果音ボタンを一度ずつ鳴らした（＝オフライン用にキャッシュされる）

## B. 音の基本
- [ ] 開始直後のテスト音（ポン）が鳴る
- [ ] 6つのBGMボタンすべてが鳴る／曲が順に繋がってループする
- [ ] 6つの効果音ボタンすべてが鳴る
- [ ] 音源を入れていないボタンはグレー（押せない）になっている

## C. 同時再生・ダッキング（最重要）
- [ ] **BGM再生中に効果音を鳴らしても、BGMが止まらない**
- [ ] 効果音を鳴らした瞬間、BGMの音量が下がり、鳴り終わると元に戻る（ダッキング）
- [ ] 同じ効果音を連打すると、重なって鳴る（前の音が切れて鳴り直しではない）
- [ ] BGMを別のボタンに切り替えると、なめらかに（約1秒で）入れ替わる
- [ ] 同じBGMボタンをもう一度押すと一時停止、もう一度で同じ位置から再開

## D. オフライン
- [ ] **機内モードにしても**、A で一度鳴らした音が全部鳴る
- [ ] 機内モードでアプリを再起動しても開く

## E. 画面が消えない（放置テスト）
- [ ] BGM再生中、画面を触らずに2〜3分放置しても再生が続く
- [ ] （iPhone）設定→画面表示と明るさ→自動ロックが「なし」になっている

## F. 全停止
- [ ] 「全停止」でBGM・効果音が即座に止まる
- [ ] 確認ダイアログが出ない

## G. 操作性
- [ ] 暗い場所でボタンの文字・色が見分けられる
- [ ] 片手・親指で押し間違えずに操作できる
- [ ] 「全停止（赤）」を他のボタンと間違えない

---

### リハで確認したい実戦シナリオ
1. 開場歓談BGM → 途中で「拍手」効果音 → BGM継続を確認
2. 「表彰・中締め」BGM中に「ドラムロール」→「ファンファーレ」を連続で
3. クイズ準備BGM(8bit)中に「8bit決定音」を連打
4. 各場面転換で BGM を切り替え → クロスフェードを確認
5. 最後に「全停止」で無音に落とす
