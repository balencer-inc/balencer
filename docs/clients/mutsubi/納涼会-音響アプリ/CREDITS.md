# 音源の出典とライセンス

アプリに入っている音源の出典です。差し替える場合も商用OKの素材を使ってください。

## ⚠ クレジット表記の条件があるもの（要確認）
下記2つは **ポケットサウンド** の素材で、無料利用時は**クレジット表記が条件**です（表記不要にする有償プランあり）。
社内イベントで流すだけなら本ファイル（CREDITS.md）への記載で足りると判断していますが、気になる場合はクレジット不要の別素材に戻せます。声をかけてください。

- s3.mp3 ドラムロール（ドン付き）… ポケットサウンド「結果発表前のドラムロール」 https://pocket-se.info/archives/479/
- 規約: https://pocket-se.info/rule/

## 表彰BGMについて
- クリーンな現代オーケストラ（魔王魂 orchestra23・16・13）で構成。ノイズなし・商用可・クレジット不要。
- ※本物の「威風堂々」実演奏は無料だと古い録音（ノイズ）しか無いため、音質を優先してこの構成にしています。定番曲そのものを使いたい場合は Audiostock 等の有料サビ版（約1,000〜2,200円）を購入して差し替え可能。
