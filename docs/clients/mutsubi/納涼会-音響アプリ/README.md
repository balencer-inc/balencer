# 納涼会 音響卓（音響操作アプリ）

**公開URL（スマホで開く）: https://noryo-audio.vercel.app**
（再デプロイしてもこのURLは変わりません。ホーム画面に追加して使ってください）

納涼会当日、スマホ1台でBGMと効果音を操作するためのアプリです。
BGMを流しながら効果音を重ねて鳴らせます（普通の音楽アプリだと効果音を鳴らした瞬間にBGMが止まってしまうのを防ぎます）。

- 対象：2026年8月7日 社内イベント
- 操作：進行役1名がスマホで担当
- 特徴：完全オフライン動作／ホーム画面に追加してフルスクリーン起動

---

## 1. まず音源ファイルを置く（一番大事）

`audio/` フォルダの中に、決まった名前でmp3ファイルを入れます。**ファイル名は下の表のとおりに。** 中身の曲は自由に差し替えられます。

### BGM（`audio/bgm/` の中）

各プレイリストは複数曲を入れられます。**入れた曲は 01 → 02 → 03 … の順に連続再生され、最後まで行くと自動で先頭に戻って繰り返します。**

| フォルダ | ボタン名 | 入れるファイル（例） |
|---|---|---|
| `audio/bgm/pl1/` | 開場歓談 | `01.mp3`, `02.mp3`, `03.mp3` … |
| `audio/bgm/pl2a/` | 卓球 | `01.mp3`, `02.mp3` … |
| `audio/bgm/pl2b/` | 卓球決勝 | `01.mp3` |
| `audio/bgm/pl2c/` | パター | `01.mp3`, `02.mp3` … |
| `audio/bgm/pl2d/` | クイズ準備 | `01.mp3`（8bit系） |
| `audio/bgm/pl3/` | 表彰・中締め | `01.mp3`, `02.mp3` … |

### 効果音（`audio/se/` の中）

1ファイルずつ、この名前で置きます。

| ファイル名 | ボタン名 |
|---|---|
| `audio/se/s1.mp3` | ファンファーレ |
| `audio/se/s2.mp3` | 拍手 |
| `audio/se/s3.mp3` | ドラムロール |
| `audio/se/s4.mp3` | 歓声 |
| `audio/se/s5.mp3` | 場面転換 |
| `audio/se/s6.mp3` | 8bit決定音 |

> **音源が無いボタンは自動でグレー（押せない状態）になります。** アプリは落ちません。あとから足せばそのボタンが使えるようになります。

## 2. 曲順・ボタン名を変えたいとき（`sounds.json`）

ボタンの名前・並び・入れる曲は `sounds.json` というファイルで決まっています。メモ帳などで開いて書き換えられます。

```json
{
  "bgm": [
    {
      "id": "pl1",
      "label": "開場歓談",           ← ボタンに出る名前
      "note": "11:45–12:55",        ← ボタンの下の小さい文字（消してもOK）
      "tracks": [                    ← 流す曲。上から順に再生してループ
        "audio/bgm/pl1/01.mp3",
        "audio/bgm/pl1/02.mp3"
      ]
    }
  ],
  "se": [
    { "id": "s1", "label": "ファンファーレ", "file": "audio/se/s1.mp3" }
  ]
}
```

- **曲を増やす**：`tracks` に行を足して、`audio/bgm/…` に同じ名前でmp3を置く
- **ボタン名を変える**：`label` を書き換える
- `id` は変えないでください（内部の目印です）

---

## 3. 本番前に1回やること（合成音モードをOFF）

音源をまだ入れていない間は、テスト用の「ピー」という合成音が代わりに鳴ります（動作確認用）。
**本物のmp3を全部入れたら**、`index.html` を開いて上のほうにある

```js
const DEV_SYNTH_FALLBACK = true;
```

を

```js
const DEV_SYNTH_FALLBACK = false;
```

に変えて保存してください。こうすると「音源が無いボタンはグレー」になり、本番で合成音が混ざる事故を防げます。
（変えなくても、本物のmp3が入っていればそちらが優先で鳴ります。念のための設定です。）

---

## 4. 当日の使い方（進行役へ）

1. ホーム画面に追加したアイコンから起動
2. 開始画面のチェック（消音スイッチOFF・自動ロックなし）を済ませて **「タップして開始」**
3. 開始直後に「ポン」とテスト音が鳴ります。**鳴らなければ消音スイッチ・音量を確認**
4. あとは画面のボタンを押すだけ

- **BGMボタン**：押すと再生。別のBGMを押すと1秒でなめらかに切り替え。**同じボタンをもう一度押すと一時停止／もう一度で再開**
- **効果音ボタン**：押した瞬間に鳴る。BGMは止まらず、効果音の間だけBGMが少し小さくなって聞き取りやすくなります
- **■全停止（赤）**：BGMも効果音も即ストップ

---

## 5. オフラインで使うために

会場のWi-Fiは当てにしないので、**事前に一度、電波のある場所でアプリを起動して全ボタンを一通り鳴らしておいてください。** 一度鳴らした音はスマホ内に保存され、機内モードでも鳴るようになります。（詳しくは `CHECKLIST.md`）

---

## 6. こまったとき

| 症状 | 対処 |
|---|---|
| 音が全く出ない | 本体側面の消音スイッチOFF／音量アップ／開始画面からやり直し |
| ボタンがグレー | そのファイルが `audio/` に無い。名前が表どおりか確認 |
| 途中で音が止まる | 自動ロックを「なし」に。充電しながら操作 |
| 曲を変えたい | `audio/` のmp3を差し替え（同じ名前で上書き）／`sounds.json` を編集 |

## 技術メモ（開発者向け）

- 単一HTML（CSS/JSインライン）＋ `sounds.json` ＋ `manifest.json` ＋ `sw.js` ＋ アイコン。ビルド不要
- BGM：`<audio>` を Web Audio(`MediaElementSource`) 経由でミックス（100MB想定のためPCM全展開はしない）
- 効果音：`AudioBuffer` に事前展開し `pointerdown` で即発音（低遅延）。ダッキングは `bgmDuck` ゲインで実装
- オフライン：Service Worker（shell先読み＋audioは実行時キャッシュ）＋ 起動時に `caches` へ音源を追加
- デスクトップブラウザ／ローカルの `index.html` 直開きでも動作
