- **何者か**: 飲食・多事業グループの持株会社。傘下に株式会社HASSIN・株式会社HARE 等の事業会社。グループ全体で約3,000名・150店舗超

- **直近の状況**: **HASSIN 制作部の定例が 2026-09-03 に始動**（毎週火曜15時）。最優先は制作システムの店舗マスター連携。トラベルダインはハポ定例への同席で"ソフトランディング"から
- **担当**: クライアント側＝**加藤 優希さん（社長）**。HD代表就任もこの方。制作部は梶原さん・次長 松沢さん・小坂さん。バレンサー側の窓口＝**加藤 梨紗さん**（社内）
- **数字/機微**: 工数粗利シミュレーションは [事業会社/hare/01_traveldine-hoshu/](事業会社/hare/01_traveldine-hoshu/) 内（内部用）
