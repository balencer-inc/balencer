飲食グループ。7期の主要顧客10社の一角（6期実績200万→7期目標400万、DXネタ積み上げ枠）。

- **担当**: 加藤さん（katou@ha-re.jp）
- **入口の建て付け**: 訪日インバウンド向けマッチングサイト「**トラベルダイン**」の**保守引き継ぎ**を"形あるもの"として受け、無形コンサルでは通しにくい社内稟議を突破。その先に社内DX・追加開発を流す（先方担当と合意済み）
