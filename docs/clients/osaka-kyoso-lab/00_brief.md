# OSAKA共創LAB ブリーフ（壁打ち用・2026-08-28時点）

## 何の事業か

大阪府教育庁「府立学校産学官共創教育モデル事業」。府立高校の生徒がチームを組み、自分の関心を起点に社会の中の課題を見つけ、**2027年2月の成果発表会までに「形にする」**ことを目指す探究プログラム。愛称 OSAKA共創LAB（OSAKA CO-CREATION LAB）。「高校発、全国初の挑戦」と位置づけられている。

- 受講期間: 2026-08-20 〜 2027-03-31
- 参加: 14チーム / 高校生66名（大阪府立・府教育センター附属・阪南など多数校の混成）
- チームは学校・学年をまたぐ混成。「違う人が集まるから一人ではできないことができる」がプログラムの思想

## 事業の設計思想（★これが背骨）

正本は [伴走ロードマップ_関係者協議資料.md](05_素材/伴走ロードマップ_関係者協議資料.md)（2026-08-18・13ページ）。伴走に入る前にここを読む。要点だけ:

- **3フェーズ**: PHASE1 コミュニケーション（チームをつくる／個→チーム）→ PHASE2 構想（やりたいことを見つける／チーム→プロジェクト）→ PHASE3 実装（社会で形にする／プロジェクト→社会との実践）
- **6つの鍵 = TRUST・WILL・TEAM・NEED・MAKE・MOVE**。PHASE1でTRUST・WILL・TEAM、PHASE2でWILL・NEED・MAKE、PHASE3でTEAM・MAKE・MOVEを主に使う
- **10の壁**: ①やりたいことが見つからない ②こんなもん ③空想 ④何から始めればいいか ⑤仲間集め ⑥チームワーク ⑦現実 ⑧試して、つくり直す ⑨届ける ⑩続ける
- **2月の到達を3段階で見る**: 最低限の到達（全チーム共通目標）／グッドシナリオ（挑戦目標）／ストレッチ（発展目標）。全チームが同じ成果物をつくる必要はない
- **企業の関わりは5レベル**: 1情報提供／2壁打ち／3接続支援／4試作支援／5共同実践。LEVEL1・2も重要な支援で、全社がLEVEL5まで進む必要はない
- **アプローチ済みの定義**: 企業へ連絡した事実ではなく、「誰に、何を、なぜ相談したいのか」を整理し、相手が答えたり判断したりできる具体度で社会へ働きかけている状態

**ファシリテーターの線引き（資料に明記されている）**
- やる: 考えや意見を引き出す／現在地・未決事項・次の行動を整理する／止まったときに問いを投げる／必要な社会の相手との接続を支援する
- やらない: **代わりに答えを決めない**。無理にテーマを決めない。外形的な成果を急いで主体性を奪わない
- **グッドシナリオはファシリテーター個人に課す達成保証ではない**（資料の合意事項1に明記）。これは阿部さんの立場を守る一文なので押さえておく
- 考え直し・規模縮小・実施見送りも、根拠ある判断なら前進として扱う

## 運営の型（伴走記録アプリ v2.1）

生徒の進捗を「**6つの鍵**」の充足（○クリア／△検討中／−未着手／↻考え直し）と「**3つのGATE**」の通過で見る。ダッシュボードが停滞のサインを自動検知して「支援が必要」なチームを上に並べる。

- 停滞のサイン: 記録途絶（14日以上）／GATE足踏み（ALMOST・RETRYが2回連続）／鍵の膠着（同じ鍵が検討中3回連続）／離脱予兆（GATE1投票の「まだ分からない」増加）／全体停止（6鍵が3回無変化）
- 「↻考え直し」は失敗ではなく前進の証として扱い、停滞判定に算入しない
- 「クリア」は完成ではなく「次へ進むための暫定合意＋証（あかし）」
- 入力の最短手順: **先に議事録（決定事項）を書き、各行に鍵をつける → 6つの鍵が自動で埋まる → 差分だけ手で直す**

→ 詳細は [伴走記録の型.md](05_素材/伴走記録の型.md)

## いま気になっている点（要確認）

1. **6つの鍵の名前は判明（TRUST・WILL・TEAM・NEED・MAKE・MOVE）したが、①〜⑥の番号対応と「何が揃えば○クリアか」の判定基準が未入手**。あわせて**3つのGATEの判定項目そのものが配布物に無い**。伴走を始める前に事務局へ要求したい
2. **停滞判定の日数・回数は「現在【要確認】の暫定値」**とPDF自身が明記。運用しながら変わる前提
3. **8/30進行シナリオの時間割が2箇所で食い違う**（全体スケジュール表 vs 各プログラム詳細）。クイズ 14:05〜14:25 / 14:05〜14:20、ワーク① 14:25〜15:00 / 14:20〜14:55、知財説明 16:30〜16:35 / 16:25〜16:30（他項目と重複）。当日の運用は詳細側が実態に近そうだが要確認
4. **担当テーブル表の名前が資料間で不一致**。スプレッドシートは「渡邉知＝5,7／須賀裕子＝10,11／宇野大介＝13,14」、テーブル配置スライドは「サトル＝5,7／平野＝11,13」。当日の卓割りは要確認
5. **伴走記録フォームのURLが2種類ある**（事務局リンク集のものとマニュアル記載のもの）。どちらが本番か要確認
6. バレンサーとしての**契約形態・フィー**が未整理（このフォルダには材料なし）
