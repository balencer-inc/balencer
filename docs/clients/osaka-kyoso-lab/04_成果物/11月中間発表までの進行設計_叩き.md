## 0. 先に決めたい前提 5つ

### ① 対面は「同日連続2コマ」で組む（2026-08-31 阿部さん判断で確定）

チーム1 → チーム2 を同じ日に続けて実施する。会場の確保が1回で済み、阿部さんの移動も1回。
チーム1で出た話をチーム2に持ち込めるので、**阿部さん自身がチーム間のハブになる**という副次効果もある。

例: 13:00–14:30 チーム1 ／ 14:45–16:15 チーム2

**出席が2〜3人だった回は60分に短縮してよい。**枠を埋めることが目的ではない。

**合同回は10月以降に1回だけ入れる。**11月の壁「人に伝わる形にできない」の練習として、他チームに説明して質問をもらう回を設ける。毎回合同にする必要はない。

### ② もう1チームの伴走者はいない（2026-08-31 確定）

8/30にマイナビ社員が1チームを見たのは**単発**。9月以降は阿部さんが2チームとも背負う。
→ だから同日連続が現実解。大学生メンターがどちらのチームに入るかは要確認。

### ③ 投稿権限

日程調整ができない＝すべてのボトルネック。今週中に事務局へ要求する。あわせて対面会場（グランフロント大阪／マイナビオフィス）の枠を**9〜11月分まとめて先に押さえる**。資料に「事前の予約・調整が必要だがファシリテーターが調整する」とあるので、動くのは阿部さん側。

### ④ 実施の下限人数

「何人来たら実施するか」を先に決めておく。**おすすめは3人**。全員待ちにすると11月に間に合わない。欠席者は後から追いつく仕組み（§4）でカバーする。

### ⑤ 中間発表の日程・形式が未確定

11月の何日か／持ち時間は何分か／企業は何社来るか。これが決まらないと最終2回（対面④⑤）の設計が動かせない。事務局へ。

## 1. 11月に持っていくもの＝5枚

ロードマップの11月支援に「資料の完成度より、問いと相談内容を整える」「発表会ではなく社会との壁打ちとして準備する」と明記されている。だから作るのは5枚だけでいい。

| # | 枚 | 中身 |
|---|---|---|
| 1 | 気になっていること | 誰の、どんな場面か（写真に撮れる具体度まで） |
| 2 | なぜ起きていると思うか | 仮説 |
| 3 | 調べたこと・聞いたこと | 事実 |
| 4 | どうなればよいと思うか | 望ましい状態 |
| 5 | **まだ分からないこと／聞いてみたいこと** | **企業への相談内容** |

**5枚目が本体。** 企業は審査員ではなく相談相手なので、聞きたいことが具体的なほど中間発表は成功する。逆に1〜4がきれいでも5がないと、ただの発表になる。

**資料は大人が作らない。** 関係者協議資料の合意事項4「大人が代わりに完成させない」。阿部さんが作るのはテンプレ1式だけで、毎回のミーティングで1枚ずつ埋まる設計にする。こうすれば11月に資料作成の時間を別途取らずに済む。後半に作成負荷を集中させると必ず破綻する。

## 3. 毎回の型（90分・固定）

毎回同じ流れにすると、高校生が「今日は何をする日か」を予測できるようになる。

| 時間 | 内容 |
|---|---|
| 0–10分 | 前回の「決まったこと1枚」を読む（**欠席者がここで追いつく**） |
| 10–20分 | 各自が持ち寄った宿題を1人1分で出す |
| 20–60分 | その日のワーク（卓を分ける。板書は下の3枠固定） |
| 60–75分 | 「もう片方のチームはこんな話をしていた」を阿部さんが持ち込む（合同回のみ、実際に相手チームへ説明） |
| 75–85分 | 決まったこと／次に確かめることを書く |
| 85–90分 | 次回日程の確認 |

### 板書は毎回この3枠に固定する

```
[ 事実 ]        聞いた・見た・調べた
[ 仮説 ]        たぶんこうだと思う
[ まだ分からない ]  確かめていない
```

9〜10月の支援に「事実・仮説・未確認を整理する」と明記されている。これを板書の形に固定すると、高校生の話が「なんとなく」から抜ける。**11月の5枚のうち2枚目と3枚目は、この板書がそのまま中身になる。**

## 4. 欠席者が追いつく仕組み

出席が揃わないのは事故ではなく常態として設計する。

毎回の終わりに「決まったこと」を1枚（3〜5行）残す。これは**伴走記録フォームの決定事項欄と同じもの**なので二重作業にならない。フォームの決定事項に鍵をつければ6つの鍵も自動で埋まる（TRUST・WILL・TEAM・NEED・MAKE・MOVE）。

欠席者はそれを読んで、次回の冒頭10分で追いつく。毎回「前回いなかった人、質問ある？」を必ず聞く。
