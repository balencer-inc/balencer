# 週次伴走記録フォーム＋伴走ダッシュボード（伴走記録アプリ v2.1）

> 原本: [操作説明PDF](https://drive.google.com/file/d/14TJwYPOuKo6LKLRvj6xs1CrcXx_uT8lU/view)（大阪府教育庁 府立学校産学官共創教育モデル事業）
> **阿部さんの毎週の実務はこれ。定例ミーティングのあと、週1回・約5分で入力する。**
> 書いた内容はそのまま伴走ダッシュボードに反映され、事務局が支援の要否を判断する材料になる。
> **生徒の実名など個人が特定できる情報は入力しない。**

## 状態の4記号

| 記号 | 意味 |
|---|---|
| ○ クリア | 次へ進む暫定合意ができ、証（あかし）がある |
| △ 検討中 | 材料はあるが未合意 |
| − 未着手 | まだ話せていない |
| ↻ 考え直し | 調べた結果を受けて再検討中（前進の証） |

## 入力のコツ（PDF記載）

1. **決定事項に鍵をつけると6つの鍵が自動で埋まる**ので、先に議事録を書いてから鍵を直すのがいちばん早い順番
2. 「クリア」は完成ではなく「次へ進むための暫定合意」という意味。迷ったら△検討中で構わない
3. 「考え直し」は失敗ではない。調査や実証を受けて方針を見直したことは探究が前進した証として記録し、停滞の判定にも算入しない

## フォームの入力項目（画面順）

| # | 項目 | 中身 |
|---|---|---|
| 1 | 記録の種類を選ぶ | ふだんは通常回のまま。GATEの判定をした週だけ「GATE実施回」に切り替える |
| 2 | 保存と入力もれ | 「記録を保存」で送信。必須の未入力があると赤い帯で出る。消えてから保存する |
| 3 | 基本情報 | チーム・ファシリテーター・実施日などは前回の入力が自動で入る。変わった項目だけ直す |
| 4 | 決定事項に鍵をつける | ★決まったことを1行書き、左のプルダウンで関連する鍵を選ぶ。選んだ鍵は下の「6つの鍵」に自動でクリアが入る |
| 5 | 6つの鍵の更新 | 自動で入った鍵には「議事録から自動反映」のバッジが付く。差分だけ手で直す |
| 6 | 状態を選ぶ | ○△−↻ の4つから選ぶ。前回値が初期表示される |
| 7 | 証（あかし）を書く | 「クリア」にした鍵は入力必須。シート・図・調査結果など、そう判断した根拠を短く書く |
| 8 | 考え直しの発生 | 方針を見直した週は「あり」にして内容を記入。失敗ではなく前進の記録として残す |
| 9 | HELP（任意） | 外部の力が必要なときだけ記入。書くと事務局のマッチング待ち一覧に載る |

## 6つの鍵

**TRUST・WILL・TEAM・NEED・MAKE・MOVE**（→ 定義と使いどころは [伴走ロードマップ_関係者協議資料.md](伴走ロードマップ_関係者協議資料.md) の 04 PHASES）

| フェーズ | 主に使う鍵 |
|---|---|
| PHASE 1 コミュニケーション（チームをつくる） | TRUST・WILL・TEAM |
| PHASE 2 構想（やりたいことを見つける） | WILL・NEED・MAKE |
| PHASE 3 実装（社会で形にする） | TEAM・MAKE・MOVE |

> ⚠️ 鍵①〜⑥の**番号と名前の対応、および各鍵の判定基準（何が揃えば○か）**は、配布物からまだ確定できていない。フォームの実画面で確認するか事務局に要求する。

## 3つのGATE

GATE1〜3の通過状況をダッシュボードで管理。判定は ALMOST／RETRY などの結果を持つ。GATE1には「投票」があり、「まだ分からない」が増えると離脱予兆として検知される。

> ⚠️ **GATE1・2・3の判定項目そのものが配布物に含まれていない。** これも要求対象。

## 伴走ダッシュボード（閲覧専用・運営／ファシリテーター向け）

フォームに入力された内容を自動で集計し、いま手を打つべきチームを上から順に並べる。入力は不要で、開くだけで最新の状態が出る。
URL: 伴走記録フォームのURL + `?page=dash`（フォーム右上の「ダッシュボードを開く →」からも移動できる）

### ① 一覧画面 ― 毎週ここから見る

**「支援が必要」に出る条件**（1つでも当てはまると出る。一度も定例記録がないチームも含む）

| サイン | 条件 |
|---|---|
| 記録途絶 | 最終記録日から14日以上あいている |
| GATE足踏み | ALMOST／RETRYが2回連続 |
| 鍵の膠着 | 同じ鍵が「検討中」のまま3回連続 |
| 離脱予兆 | GATE1投票の「まだ分からない」が増えた |
| 全体停止 | 6つの鍵が直近3回まったく変化していない |

- 「↻考え直し」があった回は全体停止にならない
- 停滞は減点ではなく、支援を届けるための検知
- ⚠️ **定義と日数は現在「要確認」の暫定値**とPDF自身が明記している

**一覧の見方**: 今週のサマリー（支援が必要／GATE判定の準備中／マッチング待ちのHELP の件数）／並び順は対応の必要度が高い順に自動／「次の一手」に誰が何をすべきかを一文で表示／6つの鍵の充足を①〜⑥の記号と「充足 n/6」で表示／最終記録からの経過日数（14日以上で赤字）

**使い方の目安**: 週のはじめに一覧を開き、赤い「要対応」の行だけを上から確認する。行の「次の一手」に書かれた内容をそのまま担当へ依頼すれば、まずは十分。

### ② チーム詳細 ― チーム名を押すと開く

停滞のサイン（記録途絶・鍵の膠着・全体停止などを自動検知）／6つの鍵×証（各鍵の根拠と、その鍵を考え直した累計回数、GATEの残項目）／GATEの現在地（3つのGATEの通過状況と再判定までに残っているチェック項目）／直近の定例記録（最新5回分の議題・決定・論点・行動・考え直し）／やり直し（方針を見直した回数と、どの鍵を何回考え直したかの内訳、GATEの再挑戦回数）
