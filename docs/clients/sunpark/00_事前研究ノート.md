# はじめに｜今回の相談をどう捉えるか

今回の相談を、

「サンパークを売却するか、息子さんへ承継するか」

という問題として捉えてはいけない。

本当のテーマは、

> **髙木さん自身の人生、サンパークという会社、息子さん、社員、株式、資産、事業を、これからどう配置し直すのか。**

である。

「会社を売る」という言葉には、複数の意味が混ざっている。

* 経営者を辞めたい
* 最終責任者から降りたい
* 日々の経営実務から離れたい
* 株式を現金化したい
* 相続問題を解決したい
* 息子に何かを残したい
* 社員を守りたい
* 会社をさらに成長させたい
* 新しいことだけをやりたい
* 自分の人生を次へ進めたい

これらは全部違う。

したがって、最初に「売る／売らない」を決めるのではなく、

**何を手放したいのか。
何を残したいのか。
誰に残したいのか。
いつまでにそうしたいのか。**

を明らかにする必要がある。

# 1｜まず理解するべき「会社」の5つの要素

会社を一つの塊として考えない。

少なくとも以下の5つに分解する。

### ① 所有

誰が株式を持つのか。

株式を持つということは、経済的価値と株主としての権利を持つということである。

### ② 経営権

誰が会社の重要な意思決定を行うのか。

所有と経営は必ずしも一致する必要はない。

### ③ 執行

誰が日々の会社運営を担うのか。

社長、COO、各事業責任者などに権限を移すことができる。

### ④ 事業

サンパークという法人そのものと、各事業は別物である。

FC事業、自社ブランド、海外事業、ウェルネス、新規事業などを、それぞれどうするかという考え方もある。

### ⑤ 髙木さん自身

ここが最も重要。

髙木さんが、

* 株主
* 代表取締役
* 会長
* 創業家
* 新規事業家
* 投資家
* 顧問

のどの役割を残したいのか。

「社長を辞める＝会社との関係がなくなる」ではない。

# 11｜「お金」の考え方

ここは阿部自身が必ず理解しておく。

髙木さんにとって、

**企業価値100億円＝100億円が手元に残る**

ではない。

企業価値、株式価値、借入、税金、アドバイザー費用などは別である。

例えば仮に、

企業価値　100億円
ネット有利子負債　30億円

なら、

概念上の株式価値は

**約70億円**

となる。

※これは説明用の単純化した例であり、サンパークの実際の評価ではない。

さらに株主が個人なのか法人なのか、取得価額はいくらなのか、どのスキームを使うのかによって税負担は変わる。

したがって比較すべきなのは、

### 売却価格

ではなく、

# 「税引後で、髙木家にいくら残るのか」

である。

# 12｜数字で見ると意思決定が変わる

仮に株式価値を70億円とする。

※以下はサンパークの査定ではなく、考え方を理解するためだけの仮定。

### 全株式売却

70億円を売却。

税金・費用等を考慮して手取りを算出する。

その代わり、

以後の会社成長によるアップサイドは基本的に買い手へ移る。

---

### 70％売却・30％保有

49億円相当を先に現金化。

21億円相当の持分を残す。

会社がその後成長し、5年後に株式価値が100億円になれば、

残り30％は理論上30億円相当になる。

逆に会社価値が下がれば、その価値も下がる。

つまり、

**今の現金化と将来のアップサイドを分ける**

ことができる。

---

### 売却せず親族承継

売却代金は入らない。

その代わり、

70億円相当の企業価値を髙木家に残す。

ただし、

相続・贈与・事業承継税制・後継者の経営能力など、別の問題が発生する。

ただし、

* 対象会社
* 後継者
* 株式

* 継続要件
* 将来の売却

などについて条件がある。

したがって、

**「息子へ株を渡したら税金はいくら？」**

という問いには、その場で回答しない。

税理士・事業承継税制の専門家を入れて設計する。

> 「全部売る必要はないかもしれない。」

あるいは、

> 「息子に会社全部を渡す必要はないんだ。」

など、

**本人も整理できていなかった本音に気づくこと。**

これができれば十分である。

# 25｜会食後に作るもの

今日聞いた話をもとに、

## 「髙木家・サンパーク 事業承継シナリオ比較」

を作る。

例えば、

### Scenario A

100％第三者売却

### Scenario B

100％親族承継

### Scenario C

所有維持＋プロ経営

### Scenario D

一部事業を息子へ承継

### Scenario E

一部売却＋一部親族承継

### Scenario F

外部資本＋5年後再判断

### Scenario G

段階的M&A

について、

| 比較項目      | 内容      |
| --------- | ------- |
| 髙木さんの経営負担 | どう変わるか  |
| 現金化       | いつ・どの程度 |
| 息子さん      | どうなるか   |
| 株式        | 誰が持つか   |
| 経営権       | 誰が持つか   |
| 社員        | 影響      |
| 会社の成長     | 可能性     |
| 税務        | 論点      |
| 実行期間      | 何年か     |
| リスク       | 何か      |
| 5年後       | どうなるか   |

を横並びにする。

そのうえで、

**企業価値、株主構成、借入、個人保証、役員、子会社、各事業の利益、息子さんの状況**

など実データを入れれば、

初めて「どれがいいか」を議論できる。

# 最後に｜阿部自身が持っておくスタンス

TSUGI&PARTNERSを作った意味は、

「会社を売る人になる」

ことではない。

経営者が何十年もかけて作った会社について、

**その人が何を大切にしてきたのかを理解したうえで、次へつなぐ。**

今回のような案件こそ、その思想が問われる。

阿部自身がすべての税務・法務・M&A実務を知っている必要はない。

しかし、

**どんな選択肢が存在し、
それぞれ何が変わり、
誰に確認すべきで、
経営者は何を決めなければならないのか。**

この「全体地図」は持っていなければならない。

そして最終的にTSUGI&PARTNERSが目指すのは、

> **売却ありきでも、親族承継ありきでもない。
> 経営者の人生と会社の未来を理解し、最善の「次」を設計する。**

というポジションである。

今日の会食は、その第一歩として考える。
