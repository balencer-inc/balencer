4. 睦備依存の耐性

睦備様は各部署に入り込み経営も握っているため消えない。上下はする。問いは「代替」ではなく「どこまで下がって耐えるか」。

損益分岐売上（粗利率75.7%・現体制）67,254,427
睦備様以外38,950,000
→ 睦備様に必要な最低額28,304,427
現在の睦備様42,050,000
許容下振れ−33%（−1,374万）

増員すると耐性が消える。

損益分岐睦備様の許容下振れ
現体制67,254,427−33%
＋1人（年780万）77,558,258−8%
＋2人87,862,089+16%必要

増員の前に非睦備を積む順番は動かせない。逆にすると、睦備様が少し下がっただけで苦しくなる。

5. 睦備型 ＝ 帯（月額）＋ 前受でプロジェクトをまぶす

これがバレンサーの商品設計。積み上げ方式だと個別のプロジェクト費が毎回説明を要するが、前受で1本にまとめれば中身の組み替えが自由になる。7期の3,200万がまさにその形で、しかも47%が原価ゼロ。

両方揃っているのは睦備様だけ。

  • ハリマ紙器印刷様 … 60周年CI/VI → ブランディング → HP → MVV浸透 → 新規事業/DX横断、と段階が進む。睦備様の初期に似ている。HP250万・MVV150万・新規事業400万をバラで積まず前受800万で1本にするのが型

目指すのは「同等」ではなく「縮小版を2社」（月額50万＋年次前受1,000万＝年1,600万）。

睦備様以外損益分岐67,254,427に対して
1社54,950,000不足1,230万
2社70,950,000到達（睦備様ゼロでも黒字）

商習慣の育成には時間がかかるが、時間がかかること自体が参入障壁。年間ロードマップを先に合意し、四半期で中身を組み替える前提にすれば、先に預かるのが相手にも合理的になる。

7. 8期の勝負所は制作2,400万の原価率

7期の粗利率75.7%は「原価ゼロの企画・ブランディング・広報」が作った数字で、阿部さんの時間そのもの。人月を買って再現できる型ではない。

8期は制作が58%を占めるため、同じ粗利率は維持できない。CG1,000万・web1,000万の原価率をどこに収めるかが利益を決める。

内製化の優先順位

原価率支払先
DXシステム開発（DB・チェックシート）70%gini
アプリ関連4件50%gini
社内DX支援（n8n）20%佐々木さん
企画設計・ブランディング・広報・セキュリティ0%自社

DXシステム開発の70%が突出。400万でginiに280万。6,500円換算で431時間。DB・チェックシートまわりはアプリ本体より剥がしやすい。

giniの年間（保守＋DXシステム＋アプリ4件）963万を6,500円換算すると1,482時間＝月123時間（フルタイム160hの77%）。高木さんの稼働をここまで上げられるかが鍵。いまは月8時間。

増やし方の規律

  • 開発・制作で増やす … 人月を積めばスケールするが粗利率50〜70%。1.2億を粗利率60%で作ると粗利7,200万＝固定費7,200万で営業利益ゼロ。単価か原価率の改善が前提
  • コンサル・伴走で増やす … 粗利率は維持できるが属人的。阿部さんの分身が要る

現実には混ぜる。「粗利率70%を割らない範囲でしか人を増やさない」を規律にすると判断がぶれない。案件は制限せず受けるが、受けた案件の粗利率を毎回見る。

8. 1.2億の形

売上1.2億・粗利率75%・営業利益率15%と置くと、使える固定費は7,200万。現在5,091万なので増員余地2,109万＝加藤さんクラス2.7人分。

1.2億は「いまの体制＋3人」で届く。ただし粗利率75%の維持が条件。

9. 決めたこと・次の論点

決めたこと

  • 賞与は売上連動から粗利連動へ（社内3人の報酬を戻し入れた「調整後粗利」を基準にする）。詳細はNotion「極秘人員計画と報酬」
  • 増員は8期に+1人まで
  • 内製化の一手目はDXシステム開発（原価率70%）をginiから高木さんへ

次の論点

  • 8期の睦備様4,170万を1本の前受にまとめる器（LIFE SHIFTが候補）。7項目を並べると単価の議論になる
  • 睦備型の2社目（トライ・ワークス様に帯を足す／ハリマ紙器印刷様を前受800万で1本に）
  • 制作2,400万の原価率をどこに収めるか。高木さんの稼働を月8時間からどこまで上げられるか
  • 4月以降の支払請求書が未格納。決算の実額が出せない（→ ai-automation-roadmap #19）
