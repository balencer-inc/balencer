# バレンサー 7期の着地と8期の設計

> 作成 2026-09-08。7期＝2025/12〜2026/11、8期＝2026/12〜2027/11。
> 金額はすべて**税抜**。賞与の個別額は本文に含めない（Notion「極秘人員計画と報酬」で別管理）。
> 元データ: 6期決算書／売掛金一覧（①）／営業管理数字マスター（④）／支払請求書／Notion「【専務用】MUTSUBI CITY PJT予算・請求 台帳」

## 1. 7期の着地

8月まで9ヶ月の実績が **55,055,211**。9〜11月に睦備様のポータル650〜800万、ハリマ様50万（HPは8期送り）を置いて——

| | 着地 | 6期比 |
|---|---|---|
| 低め | 80,933,172 | −4.1% |
| 高め | 82,433,172 | −2.3% |

**6期実績は84,400,075**（決算書）。ほぼ横ばいで着地する。

## 2. 売上は微減でも利益は倍増する

| | 6期（確定） | 7期（見込み） |
|---|---|---|
| 売上 | 84,400,075 | 81,000,000 |
| 外注費 | 30,964,780 | 18,550,000 |
| **粗利率** | **62.0%** | **75.7%** |
| **営業利益** | **4,521,674** | **約10,400,000** |

6期の当期純利益4,908,267は車両の固定資産売却益1,978,909を含む。本業の実力は営業利益452万。

**外注費が1,241万減ったことが利益改善の全て。**売上規模は変わっていない。

これが「コンサル寄りになっている」という実感の正体で、そのまま利益率の改善として出ている。

## 4. 睦備依存の耐性

睦備様は各部署に入り込み経営も握っているため消えない。**上下はする。**問いは「代替」ではなく「どこまで下がって耐えるか」。

| | |
|---|---|
| 損益分岐売上（粗利率75.7%・現体制） | 67,254,427 |
| 睦備様以外 | 38,950,000 |
| → 睦備様に必要な最低額 | 28,304,427 |
| 現在の睦備様 | 42,050,000 |
| **許容下振れ** | **−33%（−1,374万）** |

**増員すると耐性が消える。**

| | 損益分岐 | 睦備様の許容下振れ |
|---|---|---|
| 現体制 | 67,254,427 | −33% |
| ＋1人（年780万） | 77,558,258 | −8% |
| ＋2人 | 87,862,089 | +16%必要 |

**増員の前に非睦備を積む順番は動かせない。**逆にすると、睦備様が少し下がっただけで苦しくなる。

## 5. 睦備型 ＝ 帯（月額）＋ 前受でプロジェクトをまぶす

これがバレンサーの商品設計。**積み上げ方式だと個別のプロジェクト費が毎回説明を要する**が、前受で1本にまとめれば中身の組み替えが自由になる。7期の3,200万がまさにその形で、しかも47%が原価ゼロ。

**両方揃っているのは睦備様だけ。**

| | 帯（月額） | 年次前受 |
|---|---|---|
| 睦備様 | 約92万×12 | 3,200万 |
| トライ・ワークス様 | なし | 369万 |
| アダチ音研様 | 20万×12 | なし |
| 北麓様 | 20万×12 | なし |

- **トライ・ワークス様** … 前受の型はできている（8月決算前に年次一括）。帯を足せば睦備型
- **ハリマ紙器印刷様** … 60周年CI/VI → ブランディング → HP → MVV浸透 → 新規事業/DX横断、と段階が進む。睦備様の初期に似ている。HP250万・MVV150万・新規事業400万をバラで積まず**前受800万で1本**にするのが型

**目指すのは「同等」ではなく「縮小版を2社」**（月額50万＋年次前受1,000万＝年1,600万）。

| | 睦備様以外 | 損益分岐67,254,427に対して |
|---|---|---|
| 1社 | 54,950,000 | 不足1,230万 |
| **2社** | **70,950,000** | **到達（睦備様ゼロでも黒字）** |

商習慣の育成には時間がかかるが、**時間がかかること自体が参入障壁**。年間ロードマップを先に合意し、四半期で中身を組み替える前提にすれば、先に預かるのが相手にも合理的になる。

## 7. 8期の勝負所は制作2,400万の原価率

7期の粗利率75.7%は「原価ゼロの企画・ブランディング・広報」が作った数字で、**阿部さんの時間そのもの**。人月を買って再現できる型ではない。

8期は制作が58%を占めるため、**同じ粗利率は維持できない**。CG1,000万・web1,000万の原価率をどこに収めるかが利益を決める。

### 内製化の優先順位

| | 原価率 | 支払先 |
|---|---|---|
| **DXシステム開発（DB・チェックシート）** | **70%** | gini |
| アプリ関連4件 | 50% | gini |
| 社内DX支援（n8n） | 20% | 佐々木さん |
| 企画設計・ブランディング・広報・セキュリティ | 0% | 自社 |

**DXシステム開発の70%が突出。**400万でginiに280万。6,500円換算で431時間。DB・チェックシートまわりはアプリ本体より剥がしやすい。

giniの年間（保守＋DXシステム＋アプリ4件）963万を6,500円換算すると1,482時間＝**月123時間**（フルタイム160hの77%）。高木さんの稼働をここまで上げられるかが鍵。いまは**月8時間**。

### 増やし方の規律

- **開発・制作で増やす** … 人月を積めばスケールするが粗利率50〜70%。1.2億を粗利率60%で作ると粗利7,200万＝固定費7,200万で**営業利益ゼロ**。単価か原価率の改善が前提
- **コンサル・伴走で増やす** … 粗利率は維持できるが属人的。阿部さんの分身が要る

現実には混ぜる。**「粗利率70%を割らない範囲でしか人を増やさない」**を規律にすると判断がぶれない。案件は制限せず受けるが、受けた案件の粗利率を毎回見る。

## 8. 1.2億の形

売上1.2億・粗利率75%・営業利益率15%と置くと、使える固定費は7,200万。現在5,091万なので**増員余地2,109万＝加藤さんクラス2.7人分**。

**1.2億は「いまの体制＋3人」で届く。**ただし粗利率75%の維持が条件。

## 9. 決めたこと・次の論点

**決めたこと**

- 賞与は売上連動から**粗利連動**へ（社内3人の報酬を戻し入れた「調整後粗利」を基準にする）。詳細はNotion「極秘人員計画と報酬」
- 増員は8期に**+1人まで**
- 内製化の一手目は**DXシステム開発（原価率70%）をginiから高木さんへ**

**次の論点**

- 8期の睦備様4,170万を**1本の前受にまとめる器**（LIFE SHIFTが候補）。7項目を並べると単価の議論になる
- 睦備型の**2社目**（トライ・ワークス様に帯を足す／ハリマ紙器印刷様を前受800万で1本に）
- 制作2,400万の原価率をどこに収めるか。高木さんの稼働を月8時間からどこまで上げられるか
- 4月以降の支払請求書が未格納。決算の実額が出せない（→ ai-automation-roadmap #19）
