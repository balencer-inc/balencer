## 4. うまく出すコツ／崩れた時の追い足し

image2はデザイン力が高いが、**1枚に載せる日本語が多いほど文字は崩れやすい**。密度を上げたい今回は、以下で品質を担保する。

- **1枚ずつ生成し、気に入るまで2〜3回回す**（同じプロンプトで再生成すると当たりが出る）。
- **数字・会社概要の表など「正確さが命」のスライド（11・15）は、デザインだけ生成 → Googleスライド/Keynoteで文字を上書き**が最も確実。
- 追い足しプロンプト：
  - 文字化け → `文字が一部崩れています。日本語をすべて正確な漢字・かな・英数字で、誤字なく描き直してください。文章はこれ以上増やさないで。`
  - 密度が足りない → `もっと誌面の密度を上げてください。見出し・リード・小見出し・図版・ページ番号を、余白を保ちながらリッチに構成して。`
  - 絵柄を揃える → `前のページと同じアートディレクション（オフホワイト×墨黒×蛍光イエロー、デュオトーンの抽象ビジュアル、マガジングリッド）で、レイアウトだけ変えて。`
  - 画像をもっと主役に → `テキストを減らし、象徴的なビジュアルを画面の主役にして、キャッチコピー一行を大きく置く構成にして。`
