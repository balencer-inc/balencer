## 書式（既存請求書の型・踏襲する）

| ブロック | 中身 |
|---|---|
| ヘッダ | 「請 求 書」中央・字間を広く／右上に 作成日・No |
| 宛名 | 左上に社名＋御中（社名に下線） |
| 発行者 | 右上に上記6行 |
| リード | 「下記の通りご請求申し上げます。」 |
| 合計金額 | 明細の上に大きく1回出す（税込） |
| 明細 | **商品 ／ 詳細 ／ 金額**の3列。**金額は税抜**で記載 |
| 集計 | 小計（10%対象）／（8%対象）／消費税（10%対象）／（8%対象）／合計金額 |
| 振込先 | 【振込先】【口 座】【口座名義】 |
| 支払期日 | 「お支払い期日」 |
| 備考 | 「恐れ入りますが振込手数料は貴社にてご負担をお願いいたします」を定型で入れる |

## 消費税の扱い（重要）

- **明細金額は税抜**、消費税は下部で別途加算する（既存書式）
- 契約が「税込」表記の場合は税抜に換算して明細に入れる。**端数処理は税率ごとの合計に対して1回だけ**（明細ごとの端数処理はインボイス制度で不可）
- 換算のコツ: 各行 `round(税込 / 1.1)` で税抜を出し、合計に対して `int(小計 × 0.1)` で消費税を計算すると、契約上の税込総額とぴったり一致することが多い。**生成後は必ずPythonで検算を出す**（`feedback_finance_sheet_verification`）

## 支払サイトの既定

- バレンサー標準: **末日締め・翌月末払い**
- 顧客ごとの契約が優先。各顧客の `docs/clients/<スラッグ>/02_契約・見積/` を確認する

## 源泉徴収について

- 報酬・料金等の源泉徴収の対象は**個人**への支払い。**法人への支払いは原則不要**
- 契約書に控除条項があっても個人向けひな型の流用であることが多い。**法人取引なら控除なしの総額で請求**し、先方経理と突き合わせる
- 実例: ファイアープレイス様の契約書（別紙2）に控除条項あり → 法人取引なので控除なしで請求（2026-09-03）
