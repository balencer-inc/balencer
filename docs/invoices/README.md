# docs/invoices/ — 請求書の作業場（自社・全顧客分）

> 見積が `docs/estimates/` なので、その並びで請求書はここ。
> 目的は「請求書スキル（invoice）を作って、顧客が増えても発行が1指示で終わる状態にすること」。
> 設計シードは [docs/_knowledge/ai-automation-roadmap.md](../_knowledge/ai-automation-roadmap.md) の **#18** と末尾の「請求書スキルの設計シード」。

## まずここに入れてほしい材料（新セッションの着手前に）

`00_材料/` に放り込んでください。読み取ってスキルの型に落とします。

- **過去に発行した請求書**（PDFでもExcelでも1〜2通あれば十分。書式と採番の癖が分かる）
- **適格請求書発行事業者登録番号**が載っている書類（登録通知書など）
- **振込先口座**の情報 ※これは `99_local/` へ
- 顧問税理士から書式について指示があればそのメモ

## フォルダの意味

| | |
|---|---|
| `00_材料/` | 阿部さんが置く材料。読み取り用。git管理**する**（登録番号などは公開情報） |
| `99_local/` | **git管理外**。口座番号など、リポジトリに残したくないもの |
| （今後） | `<顧客スラッグ>/` 顧客別の発行済み請求書 |
