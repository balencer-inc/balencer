# 会社の記憶（仮称）— 自社商品プロジェクト

- **これは何か**: バレンサーが既にやっていること（会社の意思を構造化して、組織・ブランド・業務・AIに通す）を、繰り返し売れる形にする自社商品開発プロジェクト
- **なぜやるか**: 4領域の出口が1つに束ねられていないため、案件ごとにゼロから作っている。共通の骨格を持てば、AIが強くなるほど有利になる側に立てる
- **商品の中身**: 会社の記憶を **A〜Hの8ブロック**（A会社の定義／B事業と商品／C顧客／D決め方／E業務の型／F言葉とデザインの基準／G記録の置き場ルール／HAIへの渡し方）で構造化して納め、顧客が自分で更新し続ける状態にする
- **設計の肝**: **CとDは経営の会議に同席していないと書けない**。ここが外注に落ちない核であり、経営の隣に立つことの実利
- **現在地（2026-09-04）**: 設計・料金・診断が v0.3。AI審査員4人の採点を2周（平均59点 → 73点）。**対外化は宿題が片付くまで止めている**
